# Avatars du widget Présence

Déposez ici une image par personne (PNG), nommée d'après le prénom utilisé dans les infos « statut Prénom »,
en minuscules et sans accents :

- `will.png` : avatar de Will, utilisé pour tous ses états ;
- `will-2.png` : avatar facultatif pour un état précis (ici le code 2, « Au taf ») ;
- `nath.png`, `nath-4.png`, …

Sans image, l'écran affiche l'initiale dans un rond de la couleur de l'état.
Images carrées conseillées (ex. 300 × 300), sans bandeau : l'écran ajoute lui-même le bandeau d'état.
